تلویزیونت ال‌جی، سامسونگ یا غیر اندرویدیه؟

نیازی به نصب نیست. مرورگر تلویزیون رو باز کن، آدرس سایت مای موویز رو بنویس و آخرش /tv رو اضافه کن. برای ورود هم یک کد کوتاه روی صفحه میاد که با گوشیت تاییدش می‌کنی، بدون تایپ ایمیل و رمز با کنترل.

راهنمای نصب

اپلیکیشن‌های مای موویز مستقیم از همین صفحه منتشر میشن، نه از فروشگاه‌ها. برای همین اولین بار دستگاهت یک اجازه کوچیک ازت می‌خواد.

موبایل اندروید
  1. فایل نصب رو دانلود کن و از بخش دانلودهای گوشی بازش کن.
  2. اگه اندروید اجازه نصب خواست، روی Settings بزن، گزینه Allow from this source رو روشن کن و برگرد.
  3. روی Install بزن. اگه Play Protect هشدار داد، More details و بعد Install anyway رو انتخاب کن.
  4. اپ رو باز کن و با کلید اتصال موبایل وارد حسابت شو.

روی بعضی گوشی‌های سامسونگ، گزینه Auto Blocker جلوی نصب رو می‌گیره. اگه نصب نشد، از تنظیمات و بخش Security and privacy موقتا خاموشش کن و بعد از نصب دوباره روشنش کن.

اندروید تی‌وی و اندروید باکس

قبل از نصب: اجازه نصب رو روشن کن

توی تلویزیون برو به Settings، بعد Device Preferences، بعد Security & restrictions و Unknown sources رو برای برنامه‌ای که فایل رو باهاش باز می‌کنی روشن کن. اگه پیداش نکردی نگران نباش، موقع نصب خود تلویزیون راهش رو نشونت میده.

روش ساده: با برنامه Downloader

  1. برنامه Downloader by AFTVnews رو از فروشگاه تلویزیون نصب کن.
  2. توی کادر آدرسش بنویس mymovz.github.io تا همین صفحه باز بشه.
  3. روی «دانلود اپلیکیشن تلویزیون» بزن، صبر کن دانلود تموم بشه و Install رو انتخاب کن.
  4. مای موویز رو از لیست برنامه‌ها باز کن و با کلید اتصال تلویزیون وارد شو.

روش دوم: با فلش

  1. فایل نصب رو با گوشی یا کامپیوتر دانلود کن و روی فلش بریز.
  2. فلش رو به تلویزیون وصل کن و با مدیریت فایل تلویزیون (مثلا File Commander) بازش کن.
  3. روی فایل بزن، Install رو انتخاب کن و بعد با کلید اتصال وارد شو.
ویندوز
  1. فایل Setup رو اجرا کن. اگه ویندوز پنجره Windows protected your PC رو نشون داد، روی More info و بعد Run anyway بزن.
  2. مسیر نصب رو انتخاب کن. پیش‌نیازها (.NET Framework 4.5.2 و VC++ 2015) اگه لازم باشن خودکار نصب میشن، که ممکنه تا ۱۰ دقیقه طول بکشه.
  3. مای موویز رو از روی دسکتاپ باز کن و با همون ایمیل و رمز سایت وارد شو. نسخه ویندوز کلید اتصال لازم نداره.

سوال‌های پرتکرار

نصب اپلیکیشن‌ها رایگانه؟

بله، نصب همه اپلیکیشن‌ها و ساخت کلید اتصال رایگانه. شرایط تماشا و اشتراک رو توی خود اپ و سایت می‌بینی.

کلید اتصال رو وارد می‌کنم ولی اپ میگه اشتباهه، چرا؟

هر کلید فقط ۳۰ دقیقه اعتبار داره و فقط یک بار کار می‌کنه. اگه دیر واردش کردی یا قبلا روی دستگاه دیگه‌ای استفاده شده، از صفحه «کلیدهای اتصال» یک کلید تازه بگیر. حروف بزرگ و کوچیک هم فرقی نداره.

پیام میده به سقف دستگاه‌ها رسیدی، چی کار کنم؟

توی صفحه «کلیدهای اتصال»، از بخش «مدیریت دستگاه‌های متصل شده» دستگاهی که دیگه استفاده نمی‌کنی رو با «حذف دسترسی» بردار تا جا باز بشه.

توی خود اپ می‌تونم ثبت‌نام کنم؟

نه، ثبت‌نام، بازیابی رمز و خرید اشتراک فقط از سایت انجام میشه. توی سایت حسابت رو بساز، بعد با کلید اتصال وارد اپ شو.

چرا موقع نصب، گوشی یا ویندوز هشدار میده؟

چون اپلیکیشن‌ها مستقیم از همین صفحه منتشر میشن، نه از فروشگاه‌ها. اندروید یک بار اجازه نصب از این منبع رو می‌خواد و ویندوز پنجره Windows protected your PC رو نشون میده. راه هر دو توی راهنمای نصب هست.

چطور اپلیکیشن رو به‌روز کنم؟

اپلیکیشن‌های اندروید وقتی نسخه تازه بیاد خودشون خبر میدن. هر وقت هم خواستی، نسخه جدید رو از همین صفحه بگیر و روی نسخه قبلی نصب کن، لازم نیست قبلی رو پاک کنی.

آیفون دارم، اپلیکیشن هست؟

فعلا برای آیفون اپلیکیشن نداریم. سایت مای موویز روی مرورگر آیفون کامل کار می‌کنه.
